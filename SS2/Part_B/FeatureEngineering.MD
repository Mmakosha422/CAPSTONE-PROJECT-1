# Feature Engineering

The feature engineering stage creates additional variables that may provide useful information for predicting whether a patient will be readmitted within 30 days.

The feature engineering script used for this stage is:

`feature_engineering.py`

The script is located in:

`SS2/Part_B/feature_engineering.py`

## How to Run the Script

The script can be executed from the project root using:

```powershell
& "$env:USERPROFILE\anaconda3\envs\ds182\python.exe" SS2\Part_B\feature_engineering.py
