# Model 1 - Logistic Regression

The first machine-learning model used in this project is Logistic Regression.

Logistic Regression is used as a binary classification model to predict whether a patient will be readmitted to hospital within 30 days.

The model script is:

`model1.py`

The script is located in:

`SS2/Part_B/model1.py`

## How to Run the Model

The model can be executed from the project root using:

```powershell
& "$env:USERPROFILE\anaconda3\envs\ds182\python.exe" SS2\Part_B\model1.py
