# Preprocessing

## Overview

The preprocessing stage prepares the Diabetes 130-US Hospitals dataset for machine-learning modelling.

The preprocessing script used for this stage is:

`preprocessing.py`

The script is located in:

`SS2/Part_B/preprocessing.py`
